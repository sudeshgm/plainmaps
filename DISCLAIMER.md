# Disclaimer

This is not legal advice. A disclaimer does not make a copied database legal, and it does not protect you if the data itself was taken from someone else.

Rules for every table in this repository:

- Include only codes that are officially assigned. Do not add a code for a place that has no official code. `XK` is not an ISO 3166-1 code, so it is not in the country table, and `country_name("XK")` returns `None`.
- Do not copy a table from a library or a standard whose license is not MIT or Apache-2.0. Write the names as ordinary English words.
- This is not an official ISO product. ISO 3166-1 is published by ISO. These are common English names for the assigned alpha-2 codes, not the official ISO wording.
- If a code is missing or not real, the lookup returns `None`. Do not guess.
- The data can be wrong. There is no warranty.

If a proposed table fails any rule above, do not add it.
